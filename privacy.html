Privacy policy

Effective: 22 September 2026

Air Drive Backup Personal is operated for the account owner’s personal use. It reads selected local files and settings to create backups in that owner’s Google Drive.

Google data and permissions

The utility requests the drive.file permission to create and manage files used with this application. OAuth credentials are stored locally with restricted file permissions. Backup status and integrity metadata are kept locally. Backup contents and credentials are not published on this website.

Use and sharing

Google user data is used only for backup, integrity verification, restoration, and retention management. The operator does not sell it or use it for advertising. Backup content is sent to the owner’s Google Drive; backup status notifications may be sent to the owner’s configured notification channel. The utility has no advertising or analytics service.

Retention and control

The configured policy retains the latest five successful cloud backups. The owner can remove backups from Drive and revoke the application’s access in Google Account permissions. Revoking access stops future access; it does not itself delete stored backups.

This website

This static information site uses no analytics or tracking scripts. GitHub Pages may process visitor IP addresses for hosting security under GitHub’s privacy statement.
