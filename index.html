Air Drive Backup Personal

A personal desktop backup utility operated by the owner of this GitHub account. It copies selected files and settings from the owner’s MacBook Air to the owner’s Google Drive using rclone.

This is a personal utility, not a public backup service. Google access is granted through OAuth. This website does not accept uploads or sign-ins and does not contain backup files, account credentials, or access tokens.
